New-thread composer: send-button variants

Five options for the top composer in the 392 pt Bobbin popover, each shown empty (send disabled) and typed (send enabled).

  • Return submits; no return-key glyph is drawn
  • Working-folder control present in every variant
  • Empty draft disables send, visibly
  • Rendered 1 px = 1 pt
01

Detached Circle

current implementation

Uses the same detached 30 pt send control as the conversation composer, so nothing new to learn. Its button and gap cost 38 pt of text width, and the circle drifts away from the folder chip as the field grows.

02

Inset Circle

selected

Keeps the familiar ink circle but tucks it inside the rounded field, so the control reads as one object and the field reclaims the full 372 pt. The 5 pt inset makes the text box feel slightly taller when empty.

03

Footer Rail

room to grow

A hairline footer inside the field gives the folder chip and a small send pill a stable home and leaves space for future per-thread controls. It adds about 22 pt of permanent height to the top of the list.

04

Flush Trailing Cell

one control

Send becomes a full-height segment of the field, divided by a hairline like a stepper, so it can never fall out of alignment as the text grows. Its disabled state is a dimmed glyph rather than a dimmed shape.

05

Accent Send

bolder

The only coloured pixel in the popover is the send button, so readiness is legible at a glance and the disabled ring is unmistakably inert. It spends Bobbin's single accent on a control the keyboard usually triggers instead.

Recommendation

02: Inset Circle. It keeps the ink circle and the 30 pt hit target the conversation composer already ships, so the two composers stay one visual language. Moving it inside the field makes the new-thread control read as a single object and returns 38 pt of width to the text.

  • Take 04 if alignment as the field grows to three lines is the priority; it is the most structurally sound, just the quietest disabled state.
  • Take 03 only if a model or review-mode control is coming to this composer soon — otherwise the extra height is unearned.
  • 05 is the bolder option and the clearest disabled state, but it makes send the loudest thing in a window whose point is quiet.
  • All five keep Return submitting from the keyboard with no return-key glyph drawn.
