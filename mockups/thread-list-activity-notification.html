Thread rows: the same two meanings, carried inside

The menu bar now says working (breathing core) and something came back (lower-right dot). Opening Bobbin should answer which thread with the same vocabulary, not a second one. Each row gets a 6 pt mark in a fixed leading slot: accent, breathing while that thread runs; ink, still plus a semibold title while it holds a reply you have not opened.

This is the existing ThreadRow with three changes: the slot is always reserved so titles never shift, the running dot breathes in step with the menu-bar core, and accessibility moves state into the row’s value. Nothing else in the popover moves.

2 · Reserved slot vs today’s conditional dot

Same timeline on both lists: a thread finishes while the list is open, then you open it. Watch the title column. Press Play, or step it.

state: running

Reserved slot proposed

Every row indents 13 pt for the slot. Titles form one column; the mark appears and clears in place.

  • Nothing jumps. Finishing, opening, or a neighbour’s state change never moves your text.
  • The marks line up vertically, so scanning “anything new?” is one glance down the gutter.
  • Cost is 13 pt of leading indent on a 376 pt row, and the SAVED label moves to the same column.

Conditional (today) rejected

The dot is inserted only when needed, so a title shifts 13 pt each time state changes.

  • Titles shift left when you open a thread, i.e. exactly when your eye is on that row.
  • Rows are ragged once any thread is flagged; quiet titles start 13 pt left of flagged ones.
  • The extra 13 pt saved on quiet rows never matters at this width.

4 · Why the running dot breathes, and how little

The list is on screen only while the popover is open, so the cue can be quieter than the menu bar’s, not louder.

Breathing accent dot chosen

  • Same breath, same clock. 20 cycles a minute, in phase with the core in the menu bar. Two things pulsing in step read as one system.
  • Confined to 6 pt. No spinner, no shimmer along the title, no progress bar. It registers when you look at the gutter.
  • Never colour-only. Metadata reads “Running”; VoiceOver reads it too.
  • Degrades to today’s row. Reduce Motion is simply the static accent dot Bobbin already ships.

Static accent dot only alternative

  • Also acceptable. Toggle it in the toolbar. It is exactly the current row.
  • What it loses: the link to the menu-bar breath, and the felt difference between “running” and “kept” when both are accent on a saved row.
  • What it saves: one 12 fps timer while the list is open with a running thread. Not a real cost.

6 · Accessibility

The row stays one button. Identity goes in the label, state in the value, so VoiceOver reads “Draft release notes, button, new reply, 2 minutes ago” and the breath never touches the accessibility tree.

7 · Contract

1. Duplicate the menu-bar states in the list? Yes. Working = accent dot, breathing. Unseen = ink dot + semibold title. Failure shares the unseen dot; the metadata says “Failed”.

2. Reserved slot. Always laid out, 6 pt + 7 pt gap, on every row including saved ones. Titles never shift.

3. Motion. Only the running dot moves: opacity 1.0 → 0.3, 3.0 s, shared phase with the menu bar. No spinner, no motion on the ink dot. Reduce Motion: static dots, 120 ms fades.

4. Saved rows compose without special cases: mark leading, star trailing, no retention fade.

5. Clearing is unchanged: opening that conversation clears it; opening the list, hovering, focusing, or scrolling does not. Stop never flags.

6. Accessibility as in section 6: label = title (+ “saved”), value = state (+ age), dots hidden.
